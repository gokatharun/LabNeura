## Method

- Operands are generated once per (operation, size, set) from the seed and converted to every library, so contents, sizes and reuse schedule are identical. NumPy no longer shares one right-hand array; every library uses a distinct right-hand operand per operand set.
- **hot**: one operand pair reused on every call. **rotating**: a pool of independent operand pairs (target working set 64 MiB, at most 128 sets) visited cyclically; each set is visited equally often per batch. The working set is larger than the M1 caches for large sizes but this is **not** measured as DRAM-cold; for small sizes the pool still fits in cache (see the working-set column).
- **allocating**: the timed call returns a new tensor/array that is released immediately (allocation and release are inside the timer for every library). LabNeura NEON writes directly into the new output; LabNeura Generic still clones then operates in place.
- **in-place**: `a op= b` on the pool's left operand (LabNeura `*_inplace`, NumPy `out=a`, PyTorch `a.op_(b)`). Operands persist, so they are mutated across calls by the same schedule in every library. Right operands are chosen per operation (ADD/SUB ≈1e-3, MUL/DIV ≈1±1e-6) so the left operand stays finite and in the normal FP32 range; this was verified after timing.
- Input construction is outside the timers. Correctness is checked before timing: pool contents equal the reference, and one application of the exact timed callable is bit-identical to NumPy float32 arithmetic for every implementation.
- Per case: calibration + one warm-up batch (identical for all implementations), then batches in rotating interleaved order; GC is disabled during timing. Each sample is the batch time divided by iterations per batch.
- API surfaces differ slightly (LabNeura/PyTorch methods, NumPy ufunc). These are end-to-end Python API timings and must not be compared with native kernel timings.
- Cells are `median (IQR/p95)` in µs per call. `~` marks IQR > 20% of the median.
- Ratios are time ratios: `X/NEON` > 1 means LabNeura NEON is faster than X.
