# SKY130 high-density standard-cell library

`sky130_fd_sc_hd__tt_025C_1v80.lib` is the SKY130 high-density standard-cell
Liberty library at the typical process, 25 C, 1.80 V corner. It was downloaded
from the OpenROAD-flow-scripts repository at commit
`64939f3717ad7c694199ba04cb98924b98022868`:

<https://github.com/The-OpenROAD-Project/OpenROAD-flow-scripts/blob/64939f3717ad7c694199ba04cb98924b98022868/flow/platforms/sky130hd/lib/sky130_fd_sc_hd__tt_025C_1v80.lib>

The standard-cell library is provided by the SkyWater SKY130 PDK. Its license
is included in [SKY130-LICENSE](./SKY130-LICENSE); the upstream source is
<https://github.com/google/skywater-pdk-libs-sky130_fd_sc_hd>.

This file is a technology-specific library, not a generic educational library.
Use it only with a flow configured for the SKY130 high-density cells and this
timing corner.
