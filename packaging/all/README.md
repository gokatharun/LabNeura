# LabNeura All

`labneura-all` is a convenience distribution that installs the complete
LabNeura Python package, including its shared core, Tensor, and EDA components.

```bash
python -m pip install labneura-all
```

This distribution contains package metadata and dependencies; the native
components are provided by `labneura-tensor` and `labneura-eda`. See the
[LabNeura repository](https://github.com/gokatharun/LabNeura) for
documentation and source code.
