# LabNeura EDA

`labneura-eda` provides LabNeura's native electronic-design-automation
bindings for working with parsed Verilog modules and projects, expressions,
ports, nets, instances, timing arcs, and standard-cell library data.

```bash
python -m pip install labneura-eda
```

The native extension is independently installable. Install `labneura` for the
complete Tensor and EDA package. See the
[LabNeura repository](https://github.com/gokatharun/LabNeura) for API
documentation and source code.
