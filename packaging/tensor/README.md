# LabNeura Tensor

`labneura-tensor` provides LabNeura's native Tensor component and CPU execution
backends, including runtime selection for supported SIMD hardware.

```bash
python -m pip install labneura-tensor
```

The component is exposed through `labneura.Tensor`. It depends on
The native extension is independently installable; install `labneura` for the
complete Tensor and EDA package.
See the [LabNeura repository](https://github.com/gokatharun/LabNeura) for API
documentation and source code.
