# LabNeura Core

`labneura-core` provides the shared Python package namespace used by LabNeura's
optional native components. Install it alone when you need the package
infrastructure without the Tensor or EDA extensions:

```bash
python -m pip install labneura-core
```

The Tensor and EDA components can be installed separately as `labneura-tensor`
and `labneura-eda`. For the complete installation, use `labneura` or
`labneura-all`.

See the [LabNeura repository](https://github.com/gokatharun/LabNeura) for
documentation and source code.
