# LabNeura

`labneura` is the platform-independent umbrella distribution. It owns the
shared Python package initializer and installs the independently built Tensor
and EDA native distributions:

```bash
python -m pip install labneura
```

Install `labneura-tensor` or `labneura-eda` directly when only one native
component is required.

See the [LabNeura repository](https://github.com/gokatharun/LabNeura) for
documentation and source code.
