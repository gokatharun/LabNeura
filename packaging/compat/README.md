# LabNeura

`labneura` is the compatibility distribution for the complete LabNeura Python
package. It installs the shared core, Tensor, and EDA distributions so the
available components can be imported from the `labneura` package.

```bash
python -m pip install labneura
```

To install only selected functionality, install `labneura-core`,
`labneura-tensor`, or `labneura-eda` directly. See the
[LabNeura repository](https://github.com/gokatharun/LabNeura) for
documentation and source code.
